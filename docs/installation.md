# Installation

## Stable release

To install atmjack, run this command in your terminal:

```sh
uv add atmjack
```

Or if you prefer to use `pip`:

```sh
pip install atmjack
```

## From source

The source files for atmjack can be downloaded from the [Github repo](https://github.com/dark/atmjack).

You can either clone the public repository:

```sh
git clone https://github.com/dark/atmjack
```

Or download the [tarball](https://github.com/dark/atmjack/tarball/main):

```sh
curl -OJL https://github.com/dark/atmjack/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd atmjack
uv sync
```
